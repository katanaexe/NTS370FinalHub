Project Title:: NTS370 Network Scanner Project Final 

Overview: This project is a bash script network scanner that creates reports. 

Purpose/ Learning: This final submission is a project for NTS370 - Shell Scripting. This class reviews advanced Linux scripting creation, deployment, and troubleshooting. 

Current Status: The script has been updated and tested against feedback from Dr. Becote and the modules. 

Future Goals: This project has grown to include various features, including live API integration, vulnerability analysis, GitHub creation and updates, output to a text file (report.txt), and function creation and calling.

Ethical consideration: Like with any penetration testing, best practices should be employed to align with regulations and compliance standards for information retrieval. Local IP address scans or scans involving only an authorized IP scope should be treated with care
